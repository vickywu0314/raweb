01

患者与随访

从建档到每次复诊，病例怎么录 · 9 个任务

新建患者档案

去新建患者 →

在哪里患者管理 → 患者列表 → ＋新建患者

  1. 填写「基本信息」，其中患者姓名为必填；研究编号、ID号可在保存后自动生成。
  2. 可以继续录入首次病例的其余 7 个模块，按卡片编号从上往下填，不必一次填完。
  3. 随时点「暂存草稿」；确认无误后点「保存并完成建档」。
录入要点一人一档，研究编号唯一。确诊日期、症状首次出现日期、入组日期分别记录，不相互替代。

拍照导入纸质病历

去试试拍照导入 →

在哪里新建患者 / 新增随访页右上角「AI纸质病历拍照导入」

  1. 点击「AI纸质病历拍照导入」，选择一张或多张病历照片。
  2. 点「开始 AI 识别」，系统按模块回填候选值。
  3. 逐个模块核对回填内容，修改识别错误的字段后再保存。
  4. 只有血常规报告时，也可以在「辅助检查」里就地拍照识别。
录入要点AI 只辅助提取，不会自动下临床结论，也不会把未识别的字段填成「正常」。关键字段保存前必须人工复核。

录入一次随访

去随访管理 →

在哪里随访管理 → 选中患者 → ＋新增随访；或 患者详情 → ＋新增随访

  1. 在随访管理中选中患者（单选），点上方「＋新增随访」；也可以在患者详情页点「＋新增随访」。
  2. 「基本信息」沿用患者档案，只读不可改；如需更正，请到患者档案中修改。
  3. 依次填写病史病情、辅助检查、病情评估、治疗方案等模块，本次随访时间默认为今天。
  4. 点「保存本次随访」，保存后自动回到患者详情。
录入要点随访日期、检验日期、影像日期各自保留真实日期，不要统一改成随访日期。例：9/10 门诊随访，关联 9/08 的 CRP 和 8/29 的超声，三个日期都保留。

记录检验与影像结果

查看辅助检查模块 →

在哪里新建患者 / 新增随访 → 辅助检查

  1. 按报告录入项目名称、数值和单位；参考范围和报告日期一并填写。
  2. 没做的检查留空，不要填「正常」。
  3. 血常规可以直接拍照识别，识别后逐项核对。
录入要点保留原始事实：原始数值、原始单位、参考范围、报告日期。不要把「高于参考范围」替换成主观判断；未检查 ≠ 正常。

录入疾病活动度

查看病情评估模块 →

在哪里新建患者 / 新增随访 → 病情评估

  1. 录入组成项：压痛关节数 TJC28、肿胀关节数 SJC28、患者总体评价，以及 ESR / CRP。
  2. DAS28 由系统计算，不需要手算后再填。
  3. HAQ、疼痛 VAS 等患者报告结局按问卷原始结果录入。
录入要点只录组成项，结果由系统计算，并保留所用公式和数据版本。不熟悉评分标准，可以先看学习中心的「疾病活动度评估」。
去学习中心看评分标准 →

记录治疗调整与不良反应

查看治疗方案模块 →

在哪里新建患者 / 新增随访 → 治疗方案、不良反应

  1. 用药的开始、加量、减量、停药、重新启用，都分别记录为一次调整，并写明原因。
  2. 出现不良反应时，在「不良反应」模块记录，并注明对用药采取的措施。
录入要点按「用药过程」记录，不覆盖历史方案。不良事件与用药调整可以关联，但系统不自动推断因果。

修改患者档案与随访周期

去患者列表选择患者 →

在哪里患者详情 → 编辑档案

  1. 在患者详情页点「编辑档案」，修改姓名、联系方式、研究编号等基本信息。
  2. 在「随访方案」中设置随访周期（每 3 / 6 / 12 个月），页面会即时显示下次随访的预计日期。
  3. 修改过的字段会高亮显示；保存后逐项写入该患者的「修改记录」。
录入要点ID号为系统主键，不可修改。随访周期决定随访管理中的提醒日期：疾病活动期建议每 3 个月，达标并稳定后可延长到 6–12 个月，以研究方案为准。

修改已录入的随访

去患者列表选择患者 →

在哪里患者详情 → 点击某次随访 → 编辑本次随访

  1. 在随访时间线中打开要修改的那次访视，点「编辑本次随访」。
  2. 修改对应模块后点「保存修改」，访视详情顶部会列出「本次录入内容」。
  3. 每次修改都会记录修改了几项，可在患者详情底部的「修改记录」中查看。

找出需要随访的患者

去随访管理 →

在哪里研究执行 → 随访管理

  1. 在「随访状态」中选择「已逾期」或「14 天内到期」。
  2. 列表按预计日期排序，最该随访的排在最前。
  3. 选中患者后直接点「＋新增随访」录入。
02

数据质量

发现并补齐缺失，让数据可以用于研究 · 2 个任务

处理数据质控问题

去数据质控 →

在哪里研究执行 → 数据质控

  1. 按「问题类型」筛选：缺失、逻辑冲突（异常值与随访缺失检查二期上线）。
  2. 点击问题所在行，系统会直接定位到病历中缺失或有问题的位置（黄色闪烁提示）。
  3. 补录或核实后点「返回数据质控」，列表会保留你之前的筛选和页码。
录入要点确实无法获取的数据保持为空并标记待核实；不要用 0、-1、999 代替缺失，也不要把「不确定」填成阴性。

找出资料待补全的患者

去患者列表 →

在哪里患者管理 → 患者列表

  1. 点列表标题下「XX 位资料待补全」中带下划线的数字，一键筛出这些患者。
  2. 也可以在筛选栏的「全部患者 / 数据完整 / 数据缺失」下拉中选择。
03

分析与研究

看懂一个患者，建立研究队列 · 4 个任务

看懂一个患者的病程

去选择患者 →

在哪里患者详情 → 病程分析；或 AI 智能分析 → 选择患者

  1. 顶部「参考结论」按颜色区分：绿色为改善，蓝色为稳定，红色为恶化。
  2. 「疾病历程」把指标、治疗变化和关键事件放在同一条时间线上。
  3. 「智能洞察」中的链接会直接跳到对应随访的检查或治疗数据。
  4. 患者列表「其他病史」中的 FM / AS 标签可点击，查看该病的病程简要。

建立研究队列并分析

去队列分析 →

在哪里智能分析 → AI 智能分析 → 队列分析

  1. 用一句话写下研究问题，例如「TNFi 治疗 6 个月后仍处于中高疾病活动的患者」。
  2. 检查系统识别出的条件标签，不对的可以删掉，或在「条件筛选」中调整。
  3. 查看疾病活动分布、治疗分组达标率、亚组对比和自动发现。
  4. 点「导出队列」下载患者名单，或点「就此队列继续提问」。
解读提示组间差异是观察性描述，基线、病程、治疗线数都不同，不等同于疗效差异。

用对话向数据提问

去研究数据对话 →

在哪里智能分析 → 研究数据对话

  1. 在左侧选择对话范围：整个研究库、当前队列或单个患者。
  2. 直接提问，或点击推荐问题。
  3. 每个回答都附数据依据；点「在队列分析中打开」可以继续深入分析。

导出数据

去患者列表 →

在哪里患者列表「数据导出」；队列分析「导出队列」

  1. 患者列表：先勾选患者则只导出所选；不勾选则导出当前筛选结果。
  2. 队列分析：导出当前队列的完整名单和分析字段。
  3. 导出的 CSV 文件可以直接用 Excel 打开。

常见问题

使用中最常被问到的 7 个问题

病历填了一半，可以先离开吗？

可以。点「暂存草稿」，下次打开可以继续填写。每个模块卡片会显示「未填写 / 部分填写 / 已填写」。

不知道的值怎么填？

保持为空并标记待核实。未检查不等于正常，不确定不等于阴性；不要用 0、-1、999 代替。

检验日期和随访日期不一致怎么办？

各自保留真实日期。检验结果可以关联到本次随访，但日期不改成随访日期。

AI 识别的结果不对怎么办？

直接在对应字段修改后再保存。AI 回填只是候选值，保存前需要人工核对，系统保留修改痕迹。

为什么点「返回」会回到随访管理或数据质控？

系统会回到你进入之前的页面，并保留当时的筛选条件和页码，方便连续处理多位患者。

页面上标注的「演示数据」是什么意思？

当前为原型演示版，部分分析字段按规则生成，用于展示功能，不代表真实临床结论。

新建的患者、录入的随访保存在哪里？

演示版保存在当前浏览器本机，刷新后仍在，换一台电脑或清除浏览器数据后会消失。需要重新演示时，可以点击 恢复初始状态。
